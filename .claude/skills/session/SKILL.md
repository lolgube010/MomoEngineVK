# Session ritual

Momo struggles with consistency, so keep this short, warm and low-friction. Spend about two minutes on it, not
twenty.

## start
1. Read `.claude/journal.md` (create it if missing) and skim `.claude/ledger.md`.
2. In three lines or fewer: what was done last time, any open question left over, and the suggested next step.
   **Always mention every item under "Raise next session" in the journal**, then remove the ones that got handled.
   If the journal looks stale, Momo may have switched computers, so ask whether they've pulled.
3. **Recall quiz:** ask one quick question about a lesson from an earlier journal entry, ideally one that's
   1–3 weeks old. This is spaced repetition, so keep it light. Note in the journal whether Momo nailed it.
4. Agree on **one** goal for this session, finishable in one sitting with something visible or explainable at
   the end. If energy is low, offer a fun detour (see "fun detours" in the journal).

## end
1. Ask Momo: "What did you learn today, in one sentence?" Write their answer, not your summary.
2. Append to the journal: date, goal, learned, open questions, next step. Note whether the goal held or shifted.
   Track it without judgment.
3. Go through the parking lot with Momo: move each idea into the backlog, or drop it.
4. If something was learned well, suggest Momo commit with their own message. Don't commit for them.
